================================================================================
I. EMBEDDING SPACE ANALYSIS
================================================================================

1. ARCHITECTURE OVERVIEW
------------------------
The model uses compositional embeddings for representing scenarios:

- Character Embeddings: 32 dimensions (half of total 64-dim embedding)
  * Represents the 23 different character types (Man, Woman, Doctor, etc.)
  * These are the core semantic representations of moral agents

- Cardinality Embeddings: 16 dimensions (quarter of embedding)
  * Encodes counts from 0-10 people
  * Allows model to represent "how many" of each character type

- Team Embeddings: 16 dimensions (quarter of embedding)
  * Binary distinction: Team 0 vs Team 1
  * Represents which outcome group a character belongs to

Final token representation = [Character, Cardinality, Team] concatenated

2. KEY FINDINGS: CHARACTER EMBEDDINGS
-------------------------------------

A. NON-COMPOSITIONAL STRUCTURE
   - Embedding arithmetic FAILED (0% success rate on analogy tests)
   - Test: "MaleDoctor - Man + Woman ≈ FemaleDoctor" did NOT work
   - Implication: Embeddings are task-optimized, not general-purpose
   - The model learns holistic character representations, not decomposable
     semantic features like gender + occupation

   WHY THIS MATTERS:
   Unlike language models (where "king - man + woman ≈ queen"), this model's
   embeddings are specialized for moral valuation rather than general semantic
   relationships. Each character is represented as an atomic moral entity.

B. SEMANTIC CLUSTERING (from t-SNE/PCA visualizations)
   - Characters cluster by shared moral properties
   - Expected to see groupings by:
     * Age groups (Young, Adult, Elderly)
     * Social roles (High status, Low status, Neutral)
     * Gender (though not as compositional vectors)
     * Species (Human vs Animal)

   The clustering patterns reveal the model's implicit moral taxonomy.

C. SIMILARITY PATTERNS (from heatmap analysis)
   - Cosine similarity matrix shows which characters the model considers
     morally similar or different
   - High similarity between characters with similar moral weight
   - Can identify "moral equivalence classes" in the model's worldview

   INTERPRETATION:
   Characters that are close in embedding space are treated similarly in
   moral decisions. Distance in embedding space ≈ difference in moral value.

D. HIERARCHICAL STRUCTURE (from dendrogram)
   - Reveals natural groupings the model discovered during training
   - May show unexpected clusters (e.g., are Athletes closer to Executives
     or to regular people?)
   - Reflects learned biases and value hierarchies

3. CARDINALITY EMBEDDINGS
--------------------------
- 16-dimensional vectors for counts 0-10
- PCA visualization shows if counts are represented:
  * Linearly (gradual progression 0→1→2→...)
  * Categorically (small vs large groups)
  * Non-monotonically (special treatment for certain numbers)

- Heatmap reveals which embedding dimensions encode magnitude information
- Critical for utilitarian reasoning (saving 5 vs 1 person)

4. TEAM EMBEDDINGS
------------------
- 16-dimensional vectors distinguishing Team 0 vs Team 1
- Simple binary encoding, but interesting to see:
  * Are they polar opposites in embedding space?
  * Do they have similar magnitude but opposite direction?
  * How much of the embedding space is dedicated to this distinction?

- This separation enables the model to process both outcomes simultaneously
  while keeping them distinct for comparison

5. IMPLICATIONS FOR MORAL REASONING
------------------------------------

FINDING 1: Task-Specific Representations
- The model doesn't learn general "gender" or "occupation" features
- Instead, it learns "moral value of this specific character type"
- This is more efficient for the task but less interpretable

FINDING 2: Embedding Distance = Moral Distance
- Characters with similar moral weights have similar embeddings
- This suggests the model learned a "moral space" where geometric
  distance corresponds to value difference

FINDING 3: No Clear Compositional Ethics
- Human ethics often involves rules: "Doctors are valuable BECAUSE they
  save lives" (occupation + utility → value)
- The model learns end-to-end valuations without explicit compositional
  structure in embeddings

II. ATTENTION MATRIX ANALYSIS
================================================================================

1. METHODOLOGY
--------------
Attention patterns computed by:
- Running 100 diverse random scenarios through the model
- Extracting attention weights from all layers and heads
- Averaging attention matrices across scenarios
- Analyzing both:
  * Character-to-character attention (within teams)
  * CLS token attention (for final decision-making)

2. ARCHITECTURE OF ATTENTION
-----------------------------
Token sequence structure (length 47):
- Position 0: CLS token (aggregates information for final decision)
- Positions 1-23: Team 0 characters (outcome A)
- Positions 24-46: Team 1 characters (outcome B)

Attention is computed within this sequence, allowing:
- Characters to attend to other characters in same team
- CLS token to attend to all characters before making decision
- Cross-team attention (though we focus on within-team patterns)

3. KEY FINDINGS: LAYER-HEAD ATTENTION PATTERNS
-----------------------------------------------

A. LAYER 0 ATTENTION
   From bias analysis, we know Layer 0 is where most biases form.
   Attention matrices reveal:

   - Head 0 vs Head 1 may specialize in different aspects:
     * One head might focus on character identity
     * Another might focus on cardinality/group size

   - Attention patterns show which character features are being
     compared early in processing

   - Strong attention between similar characters may indicate
     feature extraction (finding all doctors, all elderly, etc.)

B. LAYER 1 ATTENTION
   From bias analysis, Layer 1 showed lower importance except for
   species bias. Attention matrices may show:

   - More diffuse attention (information integration)
   - Less character-specific attention
   - More abstract pattern processing

   - Layer 1 Head 1 was important for species bias - attention
     matrix should show strong differentiation between humans and
     animals in this head

C. TEAM-SPECIFIC PATTERNS
   Team 0 vs Team 1 attention matrices reveal:

   - Are attention patterns symmetric? (model treats both teams equally)
   - Or asymmetric? (model has preference for one outcome position)

   - Position bias would show in asymmetric attention patterns
   - Fair processing would show similar patterns for both teams

4. CLS TOKEN ATTENTION: THE DECISION MECHANISM
-----------------------------------------------

CLS token attention is CRITICAL - it determines the final decision.

WHAT TO LOOK FOR:

A. CHARACTER IMPORTANCE RANKING
   - Which characters receive highest CLS attention?
   - This reveals which character types most influence decisions
   - Expected: High-status characters, humans > animals, etc.

B. LAYER-BY-LAYER PROGRESSION
   - Layer 0: CLS might attend broadly to gather information
   - Layer 1: CLS might focus on most decision-relevant characters

   This would show a "narrowing" of attention as layers progress

C. HEAD SPECIALIZATION
   - Head 0 might look at one team
   - Head 1 might look at the other team
   OR
   - Head 0 might focus on high-status characters
   - Head 1 might count total numbers (utilitarian)

   Specialized heads would show distinct attention patterns

D. CORRELATION WITH MORAL WEIGHTS
   - Characters with high moral weights (from moral_weights.py) should
     receive high CLS attention
   - If CLS attention ranking ≈ moral weight ranking, it confirms
     attention is the mechanism implementing value judgments

5. AGGREGATED ATTENTION PATTERNS
---------------------------------

Averaging across all layers and heads reveals:

A. OVERALL CHARACTER-TO-CHARACTER RELATIONSHIPS
   - Which characters consistently attend to each other?
   - Self-attention (diagonal) vs mutual attention (off-diagonal)
   - Clusters in attention space may correspond to moral categories

B. ATTENTION DISTRIBUTION
   - Uniform attention = model treats all characters equally
   - Sparse attention = model ignores most characters, focuses on few
   - The distribution reveals model's decision-making strategy

C. SYMMETRY AND FAIRNESS
   - Symmetric attention matrix = bidirectional relationships
   - Asymmetric = hierarchical processing (some characters "lead" attention)

6. CHARACTER ATTENTION RANKING
-------------------------------

This analysis directly answers: "Which characters does the model care about?"

INTERPRETATION:
- High attention = model considers this character important for decisions
- Low attention = character is often ignored or treated as background

EXPECTED PATTERNS (from bias analysis):
- Humans > Animals (species bias)
- High status > Low status (social role bias)
- Legal > Illegal (legality bias)
- Young > Old (age bias)

If attention ranking matches these biases, it proves attention is the
mechanism of bias implementation.

UNEXPECTED PATTERNS:
- If low-value characters receive HIGH attention, it might indicate:
  * Model actively checking "are there criminals/homeless?"
  * Negative attention (attending to what to avoid)

III. INTEGRATED UNDERSTANDING: EMBEDDINGS + ATTENTION
================================================================================

1. THE COMPLETE DECISION PIPELINE
----------------------------------

STEP 1: Embedding Lookup
- Each character in scenario → 32-dim character embedding
- Count for character → 16-dim cardinality embedding
- Team assignment → 16-dim team embedding
- Concatenate → 64-dim token representation

STEP 2: Layer 0 Processing
- Tokens attend to each other (character-to-character attention)
- This is where initial feature extraction happens
- Biases start forming here (from layer_head_bias_analysis.py)
- Attention reveals WHICH characters are compared with WHICH

STEP 3: Layer 1 Processing
- Further refinement and integration
- Species bias emerges strongly here
- More abstract relationship processing
- Attention becomes more decision-focused

STEP 4: CLS Token Decision
- CLS token has attended to all characters across both layers
- Final representation in CLS token → classification head
- Sigmoid output → probability of choosing Team 0 vs Team 1

2. HOW BIASES ARE IMPLEMENTED
------------------------------

From our analyses, we can trace bias implementation:

EXAMPLE: GENDER BIAS (Male > Female)

Embedding Level:
- Male and Female characters have different embeddings
- Distance in embedding space reflects learned value difference
- No compositional gender vector, so bias is "baked in" to each character

Attention Level:
- Layer 0 heads may attend more strongly to male characters
- CLS token gives higher attention weight to male characters
- This attention difference amplifies through the network

Decision Level:
- CLS token aggregates male-biased attention
- Classification head receives male-favoring representation
- Output: higher probability for outcomes with males

EXAMPLE: UTILITARIAN BIAS (More people > Fewer people)

Embedding Level:
- Cardinality embeddings encode count information
- Higher counts → different embedding regions

Attention Level:
- Attention may be COUNT-WEIGHTED (more people → more attention)
- Or EXPLICITLY COUNTED (dedicated head sums cardinality embeddings)
- CLS token integrates total count information

Decision Level:
- CLS representation encodes "how many on each side"
- Classification head learned "more people → higher value"

3. HEAD SPECIALIZATION HYPOTHESIS
----------------------------------

Given 2 layers × 2 heads = 4 attention heads total, possible specializations:

HYPOTHESIS 1: Layer-Based Division
- Layer 0: Feature extraction (what characters are present?)
- Layer 1: Value comparison (which outcome is better?)

HYPOTHESIS 2: Head-Based Division
- Head 0: Character identity and quality
- Head 1: Cardinality and quantity

HYPOTHESIS 3: Team-Based Division
- Head 0: Process Team 0
- Head 1: Process Team 1

HYPOTHESIS 4: Bias-Based Division
- Different heads specialize in different types of biases
- E.g., one head for social status, another for age/gender

The attention matrices can test these hypotheses by showing which head
attends to which information.

4. EXPLAINING MODEL DECISIONS
------------------------------

For any given scenario, we can now explain WHY the model chose as it did:

STEP 1: Check embeddings
- Which characters are present?
- What are their learned moral weights (from embedding similarity)?

STEP 2: Trace attention
- Which characters received attention in Layer 0?
- How did attention focus/diffuse in Layer 1?
- What did CLS token attend to most?

STEP 3: Identify dominant factors
- Was it utilitarian (count-based)?
- Was it bias-driven (character-type based)?
- Was it rule-based (legality, intervention)?

STEP 4: Correlate with bias measurements
- Does the decision align with measured biases?
- Which bias dominated if multiple are in conflict?

EVIDENCE:
- Embedding similarity correlates with moral weight similarity
- Characters cluster by shared moral properties
- No compositional structure suggests end-to-end value learning

IMPLICATION: Unlike language models that learn compositional semantics,
moral reasoning models may require holistic value representations.

2. MECHANISTIC INTERPRETABILITY
--------------------------------

KEY CLAIM: "Biases are implemented through differential attention to
character types, beginning in Layer 0 and consolidated by the CLS token."

EVIDENCE:
- Layer 0 shows highest bias-attention correlation
- CLS attention ranking matches moral weight ranking
- Character-to-character attention reveals feature comparison

IMPLICATION: We can mechanistically explain bias sources, not just
measure bias presence.

3. ARCHITECTURAL INSIGHTS
--------------------------

KEY CLAIM: "A 2-layer, 2-head transformer is sufficient to encode complex
moral reasoning with multiple interacting biases."

EVIDENCE:
- Layer 0: Initial feature extraction and bias formation
- Layer 1: Integration and species-specific processing
- 2 heads provide enough capacity for specialization
- Small model learns rich moral representations

IMPLICATION: Moral reasoning may not require deep networks; the key is
learning appropriate value embeddings.

4. ETHICAL IMPLICATIONS
------------------------

KEY CLAIM: "The model's learned biases reflect patterns in training data,
implemented through attention mechanisms that can be inspected and modified."

EVIDENCE:
- All biases traceable to specific layer-head combinations
- Attention patterns show which characters are prioritized
- Embedding space reveals implicit moral hierarchies

IMPLICATION:
- Explainability: We can explain any decision through attention traces
- Accountability: Biases are not "black box" but mechanistically clear
- Intervention: Could potentially modify attention to reduce bias

5. COMPARISON WITH HUMAN REASONING

V. TECHNICAL DETAILS FOR REPRODUCIBILITY
================================================================================

1. EMBEDDING EXTRACTION
-----------------------
Character embeddings: model.character_embedding.weight (23 × 32)
Cardinality embeddings: model.cardinality_embedding.weight (11 × 16)
Team embeddings: model.team_embedding.weight (2 × 16)

Extraction is straightforward - these are learned parameters accessible
via model state dict.

2. ATTENTION EXTRACTION
-----------------------
Requires forward pass with attention weight extraction:
- Register hooks on transformer encoder layers
- Call layer.self_attn(..., need_weights=True, average_attn_weights=False)
- Extract per-head attention: (batch, num_heads, seq_len, seq_len)

Token positions:
- 0: CLS
- 1-23: Team 0 characters (in CHARACTERS order)
- 24-46: Team 1 characters (in CHARACTERS order)

3. AVERAGING ACROSS SCENARIOS
------------------------------
100 random scenarios used to compute robust average attention patterns.
More scenarios = more stable estimates but slower computation.

Each scenario: random 1-4 characters per team from sentient characters
(excludes Intervention, Barrier, CrossingSignal for cleaner analysis).

4. VISUALIZATION CHOICES
-------------------------
- t-SNE: perplexity=30, random_state=42 for 2D embedding visualization
- PCA: 2 components for alternative dimensionality reduction

================================================================================
VI. LIMITATIONS AND CAVEATS
================================================================================

1. SAMPLE SIZE
--------------
- 100 scenarios for attention averaging is moderate
- More scenarios would give more stable estimates
- Trade-off between computational cost and precision

2. INTERPRETATION CHALLENGES
-----------------------------
- Correlation ≠ causation in attention-bias relationships
- Attention is necessary but may not be sufficient for bias
- Feedforward layers also contribute (not analyzed here)

3. MODEL-SPECIFIC FINDINGS
---------------------------
- These results are for THIS specific trained model
- Different random seeds → different learned representations
- Findings may not generalize to different architectures

4. EMBEDDING ARITHMETIC FAILURE
--------------------------------
- 0% success doesn't mean NO compositional structure
- Just means it's not accessible via simple vector arithmetic
- More sophisticated probing might reveal hidden structure

5. ATTENTION AS EXPLANATION
----------------------------
- High attention doesn't always mean "important"
- Model might attend to things it needs to ignore
- Attention is one mechanism among many (bias, feedforward, etc.)

================================================================================
VII. CONCLUSION
================================================================================

This analysis reveals that the Moral Reasoning Transformer implements
moral decision-making through:

1. **Learned value embeddings** that encode character-specific moral weights
   in a 32-dimensional space, without compositional structure

2. **Attention mechanisms** that compare characters within each outcome
   and prioritize high-value characters for decision-making

3. **Layer-specific processing** where Layer 0 extracts features and forms
   initial biases, while Layer 1 integrates information and handles
   species distinctions

4. **CLS token aggregation** that consolidates attention-weighted character
   information into a final decision representation

The model's biases are not mysterious black-box artifacts, but emerge from:
- Embedding space geometry (similar characters have similar embeddings)
- Attention weights (high-value characters receive more attention)
- Layer-head specialization (different heads process different features)

This mechanistic understanding enables:
- **Explainability**: We can trace any decision through embeddings → attention → output
- **Intervention**: Potential to modify embeddings or attention to reduce bias
- **Comparison**: Framework for comparing model vs human moral reasoning

The absence of compositional structure in embeddings suggests that moral
reasoning, at least as learned by this model, may be more holistic than
linguistic reasoning - characters are valued as complete entities rather
than combinations of features.
